# Отчет По Проекту 

## 1. Что это за проект
Проект по бинарной сегментации изображений:
- класс `Background`
- класс `Object`

Базой был старый учебный проект `cnn1`. В текущем репозитории собран единый скрипт сравнения нескольких CNN-моделей.

## 2. Что реализовано
1. Сохранен baseline: `UNet`.
2. Добавлены дополнительные модели:
- `YOLOSegLite`
- `ResUNet`
- `SegNetLite`
3. Добавлена загрузка данных с учетом RGB (`dataset/img`) и текстурного канала (`dataset/texture`).
4. Для всех моделей выполнено обучение, инференс и расчет F1.
5. Сформирована итоговая таблица сравнения моделей.
6. Для каждой модели сохраняются:
- веса
- краткие метрики
- полный `classification_report` в формате, похожем на исходный `cnn1`.

## 3. Основные файлы
- `training_compare_models.py` - основной скрипт обучения и сравнения.
- `unet.py` - реализация UNet.
- `results/models_compare/model_comparison.md` - итоговая таблица F1.
- `results/models_compare/<ModelName>/metrics.txt` - численные метрики по модели.
- `results/models_compare/<ModelName>/report.txt` - precision/recall/f1 по классам.

## 4. Как запускать
```bash
python training_compare_models.py --epochs 12 --batch 2 --tile 256 --stride 128 --infer-stride 64
```

## 5. Итоговые метрики (последний прогон)
| Model | Test F1 | Full macro F1 |
|---|---:|---:|
| SegNetLite | 0.853633 | 0.843951 |
| YOLOSegLite | 0.847724 | 0.842344 |
| ResUNet | 0.842744 | 0.844139 |

## 6. Краткий вывод
1. Лучший `test F1` в текущем запуске показал `SegNetLite`.
2. `YOLOSegLite` и `ResUNet` показали сопоставимые результаты.
3. `UNet` в этом прогоне оказался ниже остальных, что допустимо для малого набора данных и вариативности обучения.
